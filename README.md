# ZeroToShip - Sports Club Management System

> A full-stack web application developed as part of the **ZeroToShip Program**, following professional software development practices, version control workflows, and phased project delivery.

---

# Project Overview

The **Sports Club Management System** is a web-based platform designed to simplify the management of campus sports clubs, student memberships, and team rosters.

The system provides dedicated functionality for administrators and student members, allowing efficient management of sports clubs while maintaining secure access control and structured relational data.

---

# Objectives

The primary objectives of this project are:

- Develop a scalable full-stack web application
- Design a normalized relational database
- Implement secure authentication and authorization
- Maintain proper software architecture
- Follow professional Git and GitHub workflows
- Produce clear documentation for every phase
- Deliver a production-ready application

---

# User Roles

###  Administrator

The administrator can:

- Manage sports clubs
- Create, update, and delete clubs
- Assign coaches
- View registered members
- Monitor club capacity
- Manage team rosters

---

### Student Member

A student member can:

- Register an account
- Login securely
- View available sports clubs
- Join a sports club
- Leave a club
- View their enrolled clubs

# Database Design

The system consists of three primary relational entities:

- Members
- Sports Clubs
- Rosters

Relationships between these entities are maintained using foreign key constraints to ensure data consistency and integrity.
